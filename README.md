# ChronoFlow

Pesquisa aberta para tornar renderização e apresentação de jogos mais eficientes no Android e em ambientes compatíveis.

**Situação:** protótipos matemáticos anteriores (v0.1/v0.2); integração universal e renderização Vulkan real **ainda não comprovadas**.

O desenvolvimento de um núcleo portátil e adaptadores de host acontecerá em branches de trabalho. Não confundir FPS apresentados com atualizações reais de simulação.
